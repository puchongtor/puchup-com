# ร่างข้อความขาย 4 แพ็ก (ภาษาคน)

**สถานะ:** ร่างสำหรับใช้คุยลูกค้า / โพสต์ / สคริปต์ LINE — **ยังไม่ลงหน้าเว็บ**  
**อ้างอิงโฟกัส:** [90-day-focus.md](./90-day-focus.md)

---

## แพ็ก 1 — เว็บให้ลูกค้าหาของเจอแล้วทักได้  
*(แนว Advance Pro — โฟกัสหลัก)*

**ชื่อเรียกสั้น:** เว็บกิจการกลาง  
**ใครเหมาะ:** มีสินค้า/บริการหลายรายการ ลูกค้าค้นหาแล้วหาไม่เจอ หรือติดต่อยาก

**ประโยคเปิด (1 บรรทัด)**  
ลูกค้าหาสินค้าหรือบริการของคุณเจอเร็วขึ้น และทัก LINE หรือโทรหาคุณได้ทันที

**ได้อะไร**
- หน้าแรกบอกชัดว่าบริษัททำอะไร ขายอะไร
- หมวดสินค้าหรือบริการ + ลิงก์แคตตาล็อก (ถ้ามี)
- ปุ่มโทร / LINE / ฟอร์มติดต่อ โผล่ชัดทุกหน้า
- หน้าเกี่ยวกับเรา + บริการ ถ้าจำเป็น ไม่ยัดหลายสิบหน้าโดยไม่มีเหตุผล

**ไม่ขายแบบนี้**  
ไม่พูดว่า “ระบบดิจิทัล / acquisition / conversion stack”

**ราคา (แนวทางคุย — ปรับตามขอบเขต)**  
คุยตามจำนวนหน้า + ความพร้อมข้อมูลสินค้า ไม่โชว์ราคาตายตัวบนหน้าแรกจนกว่าจะมีเรทการ์ดยืนยัน

**CTA**  
ส่งรายการสินค้าหรือบริการมาทาง LINE เดี๋ยวช่วยจัดโครงหน้าให้ดูก่อน

---

## แพ็ก 2 — เว็บหน้าร้าน + หมุด Google  
*(Project ONE เวอร์ชันภาษาคน — สินค้าสำรอง)*

**ชื่อเรียกสั้น:** เว็บหน้าร้านหน้าเดียว  
**ใครเหมาะ:** ร้านมีที่ตั้งจริง อยากให้คนนำทางมา / จอง / ทัก LINE

**ประโยคเปิด**  
หน้าเดียวจบ — ลูกค้ารู้จักร้าน ดูบริการ แล้วกดโทร LINE หรือนำทางมาได้เลย

**ได้อะไร**
- เว็บหน้าเดียวบนมือถือ อ่านง่าย
- ปุ่มโทร / LINE / นำทาง Google Maps
- (ถ้าเลือกเต็ม) ช่วยจัดหมุด Google / QR หน้าร้าน

**ไม่โชว์บนหน้าขาย**  
Schema, UTM, Geo-tagging, Local Acquisition System

**ราคา (แนวทางจากของเดิม — คุยแบบผลลัพธ์)**  
- เริ่มต้นเว็บหน้าร้านอย่างเดียว: ประมาณ 9,900 บาท (รวมโดเมน+โฮสต์ปีแรกตามข้อเสนอเดิม)
- รวมช่วยหมุด Google + QR: ประมาณ 12,900 บาท  
ค่าดูแลรายเดือนคุยทีหลัง ไม่ยัดตอนปิดดีลแรก

**CTA**  
ทัก LINE บอกประเภทธุรกิจ + พื้นที่ร้าน เดี๋ยวส่งตัวอย่างร้านใกล้ๆ คุณให้ดู 3–5 แบบ

**Demo**  
โชว์แค่ร้านที่คล้ายลูกค้า ไม่เปิดคลัง 30 ร้านเป็นจุดขายหลัก

## แพ็ก 3 — ช่วยทีมขายไม่ให้ลีดหาย  
*(หลังบ้านการขาย — เงินใกล้ รองจากแพ็ก 1)*

**ชื่อเรียกสั้น:** เก็บลีดให้เป็นระเบียบ  
**ใครเหมาะ:** มีคนทัก LINE / โทรเยอะ แต่ติดตามไม่ทั่ว ลืมติดต่อกลับ

**ประโยคเปิด**  
ทุกคนที่ทักเข้ามา มีชื่อ ช่องทาง และสถานะชัด — ไม่หายในแชท

**ได้อะไร (เริ่มง่าย)**
- รายการลีดจากเว็บ / LINE / โทร
- สถานะ: ใหม่ → ติดต่อแล้ว → นัดแล้ว → ปิดการขาย / ไม่เอา
- ใครรับผิดชอบเคสไหน
- เริ่มจาก Sheet / Notion / แดชบอร์ดง่าย ก่อนทำซอฟต์ใหญ่

**ไม่ขายแบบนี้**  
ไม่เปิดด้วย “CRM ระดับองค์กร” ถ้าลูกค้ายังไม่พร้อม

**CTA**  
เล่าว่าตอนนี้ลีดอยู่ที่ไหน (LINE OA, มือถือใคร, Excel ไหม) เดี๋ยวจัดขั้นตอนให้สั้นที่สุดก่อน

---

## แพ็ก 4 — สอนทำ + รับช่วยต่อ  
*(ช่องทาง funnel — ไม่แย่งโฟกัสรับทำใน 90 วันแรก)*

**ชื่อเรียกสั้น:** สอนทำเว็บกิจการ  
**ใครเหมาะ:** อยากลองทำเองก่อน หรือทีมในบริษัทอยากดูแลคอนเทนต์เอง

**ประโยคเปิด**  
สอนโครงเว็บกิจการให้ทำเองได้ — ถ้าทำไม่ไหว มีแพ็กรับช่วยต่อให้

**ได้อะไร**
- เวิร์กช็อปสั้น: โครงหน้า ข้อความ ปุ่มติดต่อ รูป
- ตัวอย่างจากเคสจริง (เช่น Advance Pro, หน้าร้านหน้าเดียว)
- คนที่ติด ต่อแพ็ก 1 หรือ 2 ได้โดยไม่เริ่มจากศูนย์

**CTA**  
สนใจรอบสอน บอกประเภทธุรกิจมา เดี๋ยวแจ้งรอบถัดไป

---

## สคริปต์ LINE สั้น (ใช้ร่วมได้)

1. สวัสดีครับ เล่าธุรกิจสั้นๆ ได้ไหม ขายอะไร / มีหน้าร้านไหม / ลูกค้าติดต่อยังไงตอนนี้  
2. ปัญหาหลักคือ หาของไม่เจอ / ติดต่อยาก / ลีดหายในแชท / หรืออยากให้คนมาร้าน — อันไหนใกล้สุด  
3. ส่งตัวอย่าง 1 หน้า + ขอบเขตงาน ไม่ยัด Demo ทั้งคลัง  
4. นัดคุยสั้น หรือส่งใบสรุปงาน + ราคาตามแพ็กที่เข้า
