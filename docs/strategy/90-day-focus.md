# โฟกัส 90 วัน — ยืนยันแล้ว

**สถานะ:** ตัดสินใจแล้ว (ตามแผนไอเดีย PuchUp)  
**ขอบเขต:** ทิศทางธุรกิจ — ยังไม่ลงโค้ดหน้าเว็บ

## หลัก / รอง

| ลำดับ | สิ่งที่ทำ | บทบาท |
|------|----------|--------|
| 1 (หลัก) | งานออนไลน์ให้กิจการกลางที่ไม่ถนัด — แบบ Advance Pro | เครื่องยนต์รายได้ |
| 2 (หลักรอง) | แพ็กช่วยจัดข้อมูล + LINE + หน้าติดต่อ (แบ่งงานได้) | ขยายจากข้อ 1 |
| 3 (ช่องทาง) | สอนทำเว็บ / สอนออนไลน์กิจการแบบสั้น | Funnel ไม่แย่งโฟกัสรับทำ |
| 4 (สำรอง) | Project ONE หน้าร้านหน้าเดียว | SKU + ตัวอย่าง ไม่ผลักหนัก |
| 5 (รอ) | Amethez | จองที่ในระบบ ยังไม่เปิดขาย |

## สิ่งที่ทำใน 90 วัน

1. ปิดงานแบบ Advance Pro **1–2 เคสจริง** (เว็บ + แคตตาล็อก/หมวดสินค้า + ติดต่อชัด) ใช้เป็นพอร์ต
2. ขายด้วยภาษาผลลัพธ์: ลูกค้าหาของเจอ → ทัก/โทรได้ — ไม่ขายคำว่า “ระบบ”
3. เก็บ Project ONE ไว้ในพอร์ต แต่ไม่เป็นพระเอกของ puchup.com
4. คอร์ส/เวิร์กช็อปสั้นได้ แต่ไม่ตั้งเป็นธุรกิจหลักก่อนมีเคสรับทำ

## สิ่งที่ยังไม่ทำใน 90 วัน

- ไม่รีดีไซน์หน้าหลัก PuchUp ให้ Project ONE เป็น hero
- ไม่เปิดขาย Amethez เป็นสินค้า
- ไม่ผลัก retainer Maps 3,500 บาท/เดือน เป็นจุดขายหน้าแรกของ Project ONE
- ไม่ขยาย Demo showroom เป็นจุดขายหลัก

## ผู้ซื้อที่โฟกัส

- โรงงาน / อะไหล่ / B2B / บริการมืออาชีพ / กิจการกลางที่มีสินค้าหรือบริการชัด
- ทีมที่ LINE/โทรเยอะแต่ลีดหาย (ถ้าเข้าแพ็กหลังบ้าน)

## ผู้ซื้อที่ยังไม่ไล่หนัก

- ร้านอาหารคาเฟ่คลินิกแบบ Project ONE mass demo — รับเป็นโอกาสเข้ามาเอง ไม่ไล่ pipeline ใหญ่
