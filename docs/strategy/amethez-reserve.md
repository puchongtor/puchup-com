# Amethez — จองที่ในระบบ (ยังไม่เปิดขาย)

**สถานะ:** สำรองในสถาปัตยกรรมเท่านั้น  
**เงื่อนไขเปิดขาย:** มี workflow จริงจากเคสลูกค้าอย่างน้อย 1–2 เคสก่อน

## บทบาทที่จองไว้

Amethez ไม่ใช่สินค้าเดี่ยวตอนนี้ — เป็นชั้นช่วยทำงานทับบนแพ็กที่มีอยู่แล้ว

| ทับบนแพ็ก | บทบาท Amethez (อนาคต) |
|-----------|------------------------|
| เว็บกิจการกลาง (แพ็ก 1) | ช่วยตอบคำถามสินค้าเบื้องต้น / ส่งต่อคนจริง |
| เว็บหน้าร้าน (แพ็ก 2) | ช่วยคัดคำถามจอง/เมนู ก่อนเข้า LINE คน |
| หลังบ้านขาย (แพ็ก 3) | สรุปลีด สรุปแชท จัดสถานะเบื้องต้น |
| สอน (แพ็ก 4) | ยังไม่จำเป็น |

## สิ่งที่ยังไม่ทำ

- ไม่ลงหน้าขาย Amethez บน puchup.com
- ไม่สัญญา AI ในใบเสนอราคาแพ็ก 1–2 ช่วง 90 วันนี้
- ไม่ผูกแบรนด์ Amethez กับ Project ONE เป็นจุดขายหลัก

## สิ่งที่เก็บไว้ให้รอบถัดไป

1. หลังปิดเคส Advance Pro / หลังบ้านขาย — จดว่าขั้นตอนไหนคนทำซ้ำทุกวัน
2. เลือก 1 workflow (เช่น สรุปแชทลีดเข้า Sheet) ทดลองภายใน
3. ตั้งชื่อบทบาทให้ลูกค้าเข้าใจ เช่น “ตัวช่วยตอบเบื้องต้น” ก่อนใช้ชื่อแบรนด์ Amethez ถ้ายังไม่คุ้น

## ตำแหน่งในแผนภาพพอร์ต

```
PuchUp (ร่ม)
├── กิจการกลางขึ้นออนไลน์  ←── โฟกัสตอนนี้
├── Project ONE หน้าร้าน     ←── สำรอง
├── หลังบ้านการขาย          ←── ใกล้เงิน
├── สอนทำเว็บ               ←── funnel
├── พัฒนาตน                 ←── ระยะกลาง
└── Amethez                 ←── จองที่ ทับบนข้อบน เมื่อมี workflow จริง
```
